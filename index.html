Proxy (Firebase / Cloudflare Worker)

Firebase deploy karne ke baad Function URL yahan paste karein, ya Cloudflare Worker URL use karein. Firebase example: https://us-central1-PROJECT_ID.cloudfunctions.net/streamProxy?url=. Sirf base URL paste karenge to /?url= auto add hoga. Backend ko HLS playlist, segments aur CORS ko handle karna hoga. Firebase ke liye is HTML ke saath diya gaya deployment ZIP use karein.

Firebase deploy kaise karein?

Download ki hui Firebase Proxy ZIP ko extract karein, Firebase CLI install/login karein, firebase.json ke project ko apne Firebase project se connect karein, functions/.env.example ko functions/.env naam se copy karke PROXY_ALLOWED_HOSTS mein apne stream/CDN hostnames daalein, phir firebase deploy --only functions:streamProxy chalayein. Deploy ke baad Function URL upar paste karke Save aur Test karein.

Note: Browser se bina Firebase login/project approval ke secure deployment auto nahi ho sakta. Allowlist mein channel hostnames add karne honge; isse public open proxy banne se bachata hai.
